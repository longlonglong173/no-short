# NS-17 — So sánh hai khoảng thời gian

## Behavior

History in the native app and MCP panel has an opt-in comparison checkbox, off by default. The selected inclusive calendar-date range is compared with the immediately preceding equal-length range in the snapshot timezone. Both boundaries are visible. This uses the cached daily history; it makes no report or network request and does not change a pinned/live session.

The summary, each selected provider, and each provider/model row show the current and previous cost, total-token absolute/percentage changes, cost absolute/percentage changes, cache-read ratios and their change in percentage points. A model absent from one range contributes an empty retained-log aggregate; a model with unpriced usage stays unknown. A zero baseline never produces an infinite percentage.

Cost differences are available only when both aggregates have complete estimated pricing and the snapshot is fresh. Freshness matches native policy: error/stale status, age over 45 seconds, a timestamp more than 60 seconds in the future, or a different local calendar day makes exact cost deltas unavailable. The React comparison checks its clock while visible and immediately on visibility return; it does not request additional reports. Unknown/partial prices are never zero-filled. Token and cache comparisons remain available with the existing stale-data warning. Cache-read ratio is `cacheRead / (input + cacheRead + cacheWrite)`; a zero denominator is unavailable. Output is excluded.

Dates are calendar labels, not elapsed-hour windows, so DST and leap-day boundaries preserve the count of calendar days. The current partial month is compared exactly as selected, without extrapolation. Sparse history describes retained local logs only; absent rows do not establish complete account coverage. Exports retain the existing selected-range schema and explicitly exclude the comparison range.

## Interfaces and compatibility

- TypeScript `compareHistory(snapshot, provider, range, now?)` returns current/previous boundaries, summary, provider and provider/model rows, or null for unavailable/invalid history.
- Swift `UsageComparison.compare(_:provider:range:isStale:)` mirrors the same projection. The native History window owns its comparison toggle independently of live selection.
- Snapshot schema v1 and export DTOs are unchanged. EN/VI/简体中文 copy is provided on both surfaces.
