# No Short Usage0.6.1 — Experimental (2026-10-26)

Apple Silicon, macOS14+, ad-hoc signed and not Apple-notarized. Public app ZIP: `NoShortUsage-0.6.1-arm64.zip`. This release reuses the0.6.0 owner public key and canonical signed feed; no key rotation or0.6.0 asset replacement.

## What changed

NS-15 adds a visible running version and update status at the bottom of the main popover, shared with About/menu. It distinguishes not checked, checking, no newer version found, a newer version, download/install progress and retryable failures, with the last successful check time. A known newer release remains visible after closing/cancelling the installer dialog.

Daily discovery is enabled by default and can be turned off in About or Settings. Checks use Sparkle's information-only API, with at least24hours between automatic attempts across restarts; manual checks bypass that cadence. They never download archives, open installer dialogs, install or send OS notifications. Installation still uses the standard explicit confirmation and signature checks, with the existing safe shutdown drain.

## Test the real update from0.6.0

1. Run the installed0.6.0 app from Applications.
2. Open About/menu → Check for Updates; the existing0.6.0 UI should offer0.6.1.
3. Confirm Install Update, then Install and Relaunch.
4. After relaunch, the main popover should showv0.6.1. A due informational check then shows the latest known status/time.

The new daily/status UI arrives with0.6.1; it cannot appear retroactively in0.6.0. Users of0.5.0 still need to install an updater bootstrap manually once. No dummy0.6.2 release is published for this test.

## Verification and remaining acceptance

`release-validation.json`/`SHA256SUMS` identify exact source and final uploaded bytes. Source tests cover cadence across relaunch, off/manual behavior, maintenance/busy guards, retained verified metadata, failure/future-clock recovery and localized adaptive rendering. Controlled native informational probes cover newer/equal/tampered-feed/network cases with exactly one feed request and no archive/install. Prior NS-14 actual installer/relaunch evidence remains separate from the user's real0.6.0 →0.6.1 acceptance.

Snapshot schema remainsv1 and ccusage20.0.34. The MCP plugin updates separately. API-equivalent costs are estimates, not subscription billing/quota. Developer ID/notarization, clean-machine installation, Intel execution, OS permissions/login/notifications and VoiceOver remain NS-05 device gates. The release process does not replace the user's installed app.
