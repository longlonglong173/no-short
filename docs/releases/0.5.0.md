# No Short Usage 0.5.0 — Experimental (2026-10-21)

Apple Silicon download: `NoShortUsage-0.5.0-arm64.zip`, macOS 14+.
Ad-hoc signed; **not Apple-notarized**. No public Intel native app ZIP.

## Changes

NS-06–NS-12 add provider-filter parity, an adaptive scrolling popover, bounded metadata caching, a separate native History window and panel history filters, CSV/JSON export, opt-in daily/monthly budgets and safe shared-cache management. Budgets/OS notifications remain disabled by default; uninstall/disconnect guidance does not automatically alter third-party settings or remove provider logs.

All costs are API-equivalent estimates, not subscription invoices, credits or quota. Exports omit session identifiers/titles by default; opt-in session references are last-activity matches, not complete cost attribution. Snapshot schema stays v1 and ccusage stays pinned to 20.0.34. The upstream identical-timestamp/token daily-total undercount remains documented, not fixed; metadata-cache benchmark results do not establish end-to-end ccusage speedup.

## Source and exact release bytes

The release tag is `v0.5.0`. `release-validation.json` records the exact source commit/tag, test scope and file hashes; `SHA256SUMS` covers the uploaded artifacts. `runtime-manifest.json` contains hashes of the actual rebuilt helper archives/binaries, not reused older release hashes. Previous tags/assets remain unchanged.

The public native ZIP is separate from the two MCP runtime TAR archives. Installing the app does not update a separately installed Codex plugin. A plugin package is included separately. Website download links are rolled out only after the release files have been published and checked.
