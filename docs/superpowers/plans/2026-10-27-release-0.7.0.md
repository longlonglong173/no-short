# No Short Usage 0.7.0 Release Plan

> **For agentic workers:** Use superpowers:executing-plans to execute this release checklist. Owner retains PR merge authority.

**Goal:** Distribute the six merged tasks as an immutable Experimental 0.7.0 release and prepare the signed website/feed update.

**Architecture:** Reuse the existing pinned source build, runtime packaging, native bundle verification and Sparkle owner key/channel. Build local artifacts before creating a draft release; verify uploaded bytes before publication. The owner merges the reviewed release PR to deploy the website/feed.

**Tech Stack:** Bun 1.3.13, pinned Rust 1.98.1/ccusage 20.0.34, SwiftPM/Sparkle 2.10.0, GitHub Releases, Vercel Git deployment.

**Spec:** docs/releases/in-app-updates.md and docs/releases/0.7.0.md.

## Constraints and review focus

- Keep all historical releases immutable; no key generation/rotation or secret output.
- Preserve the installed app, real logs/settings and source fixture isolation.
- Keep Experimental/ad-hoc status; no notarization or Intel-device acceptance claims.
- Do not merge PRs on behalf of the owner. Prepare a concrete reviewable release and feed.
- Verify version, architecture, extracted bundle/runtime provenance, signatures and both archive/feed hashes; stale pre-patch runtime must not ship.

- [x] Align root/plugin/Usage versions at 0.7.0; document merged tasks and release limitations.
