> **For agentic workers:** use superpowers:executing-plans and test-driven-development. Each numbered NS task gets its own branch, verification, review and PR before the next NS task starts. Bounded native/engine/UI slices may use workers within the current task.

**Goal:** Complete the approved backlog NS-07 through NS-12 without merging or publishing.
**Architecture:** Keep one ccusage snapshot/scan lock; native SwiftUI/AppKit and MCP React UI consume shared contracts. Preserve schema v1, session pins, source boundaries and pricing uncertainty.
**Tech Stack:** Bun/TypeScript/React, Swift 6/AppKit/SwiftUI, ccusage 20.0.34.
**Spec:** `docs/BACKLOG.md`; NS-09 additionally `docs/superpowers/specs/2026-10-20-ns09-usage-history-window-design.md` (retained on its existing branch until NS-09).

## Global constraints
- Separate PR for each NS; dependent PRs are stacked, never auto-merged.
- Local-only usage data, three languages EN/VI/zh, no credentials or message exports.
- Do not delete source logs/settings, install hooks, enable notifications, change login or publish releases while developing.
- Estimated API-equivalent USD is not subscription billing/credits/quota.
- Version changes are only necessary for release preparation, not each unreleased source PR; keep download assets immutable.

## Review focus
1. Small screens or additional warnings must not hide controls (NS-07 tests).
2. Metadata append/rename/delete and source switches must not reuse stale titles (NS-08 filesystem tests).
3. Calendar DST/month boundaries and unknown price must not become zero (NS-09 shared fixtures).
4. CSV formula injection and default identifier redaction (NS-10 export tests).
5. Stale data, repeated refresh, reconfiguration and restart must not repeat budget alerts; concurrent scans must block cache deletion (NS-11/12 tests).
