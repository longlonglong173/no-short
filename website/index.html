A FEW DETAILS

Good to know.

What exactly is an agent skill?+

A skill is a set of instructions your AI agent can use for a specific task. no-short packages those instructions for writing and personal reporting, with compatible plugin manifests and a Skills CLI layout.

Do I need every connected service?+

No. Personal work reports use only the sources you choose. A GitHub-only report is fine; Jira and Slack are not required. At least one selected source must be connected and return verified activity.

Does no-ai-slop detect AI authorship?+

No. Its audit mode identifies observable writing patterns and explains how to improve them. It does not identify the author or assign an AI probability score.

Can I download No Short Usage?+

Yes. Download the app for a Mac with M1 or later running macOS 14+. It is experimental; macOS may block its first launch. The app is installed separately from the skills and plugin.
