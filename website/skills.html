A FEW DETAILS

Good to know.

What exactly is an agent skill?+

A skill is a set of instructions your AI agent can use for a specific task. No Short Skills includes two: editing or auditing drafts, and compiling personal work reports.

Do I need every connected service?+

No. Personal work reports use only the sources you choose. A GitHub-only report is fine; Jira and Slack are not required. At least one selected source must be connected and return verified activity.

Does no-ai-slop detect AI authorship?+

No. Its audit mode identifies observable writing patterns and explains how to improve them. It does not identify the author or assign an AI probability score.

I installed the old no-short skills. What changes?+

Use no-short-skills for future skill installations and updates. The two skills keep their instructions and supporting files. Keep the separate no-short plugin if you use the Usage panel; the menu bar app is independent.
