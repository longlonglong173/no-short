Install the app

  1. Download the ZIP above and extract it.
  2. Quit any older running copy, then move No Short Usage.app to Applications.
  3. Open the app from Applications. Click its menu bar icon to see usage.

If macOS blocks the app: follow Apple's guide ↗

Change the app language

Open ⚙ → Language / Ngôn ngữ / 语言 and choose English, Tiếng Việt or 简体中文. The choice is saved. If this menu is missing, quit the older copy and open the new app from Applications.

Read the context ring

Context is the information an AI model uses to answer within a session. The ring around each logo shows estimated usage as a share of the model’s context capacity. A dashed ring means no data yet. In All mode, each provider has its own ring. This percentage is not a subscription limit.

Change the alert threshold

By default, the icon and context ring turn red at 70%. The panel also shows a warning.

Click the icon → ⚙ → “Context alert threshold: 70%…”. Enter a number from 1 to 100 and click Save. Your choice is saved across launches.

Toggle notifications in ⚙ → “Notify via macOS when threshold is reached”. Allow notifications when prompted; Focus may hide banners.

Connect Claude Code context

In ⚙, choose “Connect Claude Code context…”, then continue in Claude Code to receive data. If you already have a custom status line, see the integration instructions in the technical guide below.

Data on your Mac

The app reads local logs and does not send logs or session titles to the developer. It may fetch public model pricing to estimate costs.

If you also install the MCP plugin, the selected session’s title, ID and usage totals are returned to ChatGPT/Codex and may become input to the AI model. The full session list is sent along as metadata for the usage panel. The receiving application’s privacy rules apply.

When you need more detail

Choose and follow sessions+

Choose a provider and session in the app; pin a session to keep it selected. For automatic following, choose “Connect automatic chat tracking…” in ⚙. The app follows submission events, not the chat tab you are viewing.

Use multiple log folders+

In ⚙, choose Codex or Claude Code log folders. Add one or more home folders containing sessions (Codex) or projects (Claude), or remove entries from the list. Review errors beside each path, then Save. Every source must be valid; Cancel keeps your previous settings. Duplicate paths and aliases are collapsed. Removing an entry does not delete its logs. Use the default-source action to clear that provider’s overrides.

Missing data or notifications+

Try Refresh and check the selected log folder. Claude context needs its separate connection. For missing banners, check macOS notification permissions and Focus.

Notifications fire once per crossing and can fire again after context falls below the threshold and reaches it again. Unknown or stale readings do not trigger an alert.

Update or remove the app+

To update, quit the app and replace it in Applications. Before removing it, disconnect automatic tracking and Claude context, turn off Open at login, then quit. Logs, caches and settings backups remain on your Mac.

Technical details and experimental status+

The app is ad-hoc signed and not notarized by Apple. The build passed basic checks on the developer’s Mac; notification banners and installation on other Macs remain unverified. The technical guide covers building from source, status line integration and data handling.
