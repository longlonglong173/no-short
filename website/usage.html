Install the experimental Apple Silicon app

  1. Download the Apple Silicon experimental app ZIP and its checksum file. No Node/Bun or API key is needed to run the app.
  2. Verify the ZIP using SHA256SUMS-context-alerts-experimental.txt. Extract it and move No Short Usage.app to Applications.
  3. Quit older running copies, then open the app from Applications. Click the menu bar icon to see usage; no Dock window is expected.

Because the app is not notarized, macOS may block it. Only open software you trust; follow Apple's app-specific guidance without disabling Gatekeeper globally.

Read the ring correctly

The ring estimates the context occupied at the latest recorded response. It is not cumulative token spending or a subscription limit. A dashed ring means unknown, not 0%. In All mode, each provider has its own ring.

For Claude context, choose “Kết nối context Claude Code…” in the gear menu, then continue in Claude Code. Existing custom status lines are preserved; manual integration instructions are in the technical guide. Until telemetry arrives, context stays unknown.

Context alerts at 70%

When measured context reaches 70%, the provider logo and its ring turn red on the menu bar. The panel also shows a warning. In All mode, each provider is checked separately.

Change the threshold (1–100%) in the gear menu → “Ngưỡng cảnh báo context: 70%…”. Turn macOS notifications on or off separately with “Thông báo macOS khi vượt ngưỡng”. The app asks for notification permission at the first crossing; Focus and macOS settings may suppress banners.

Notifications fire once per crossing, rather than on every refresh. A measured drop below the threshold rearms the next alert. Switching sessions or restarting the app does not replay an alert; unknown and stale readings do not trigger one.

Choose or follow a session

Choose a provider and a session, or pin one to keep it selected. Automatic following requires the separate opt-in tracking connection in the gear menu. Without it, the app uses the latest available usage; it cannot identify the chat tab you are viewing.

Local data and network access

Usage reads retained logs on your Mac and stores local statistics. It may fetch public model pricing; logs and session titles are not sent to the pricing service or the developer. The independent app has no developer-hosted telemetry. Using the plugin panel can make statistics available to the conversation host.

If data is missing

Check the selected log folder and whether the host has written usage. Missing pricing remains unknown; read failures keep the last result with a stale warning. Refresh manually from the popover. For offline use, cached pricing must already be available.

Remove or update the app

Before removing or moving the app, disconnect automatic tracking and Claude context, disable Open at login, then quit. Replace the app in Applications to update it. Logs, caches, context records and settings backups remain on your Mac until you remove them separately.
